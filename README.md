# agent-tool-use-briefing

Reading roundup for lab meeting on **how large-language-model agents actually get things done —
tool use and function calling** — plus one human-factors anchor paper on how people judge the
trustworthiness of health information from conversational search agents.

## Contents

- `survey.md` — polished write-up: one intro paragraph, then one section per paper with title,
  arXiv ID, and a 3–5 sentence takeaway drawn from the full text.

## How the papers were selected

- **Anchor (human factors):** "From Search Agents to Dissemination Interfaces" — located on arXiv
  by title/subject after the labmate could not recover the arXiv ID.
- **At least two additional recent papers** on LLM-based agents using tools or function calling,
  each read past the abstract (full text) before being summarized.

## Status

Work in progress. Rough per-paper extracts are collected in `notes/raw-extracts.md` while reading;
that scratch file is removed once `survey.md` is finalized, leaving exactly the README and the
polished write-up.
